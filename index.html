DeskPi Homelab

Four computers,
one rack

How I planned a compact DeskPi homelab with one network switch and one shared monitor.

I planned a 12U DeskPi RackMate T2 around four computers I already owned. A Netgear switch connects the computers to my home network. A GL.iNet Comet X lets me use one monitor, keyboard and mouse with all four, or control them from my laptop. The rack, extra shelves and accessories came to £246.18 in my shopping basket.

Fit four computers into a 10-inch rack

The RackMate T2 has 12 rack units (U) of vertical space. I allocated five shelves for the computers and switch. The Windows Intel NUC sits sideways to fit, and the Raspberry Pi 3 keeps its case. The Synology DS920+ sits beside the rack.

Connect the rack to the home network

I kept my eight-port Netgear GS108. A 2 m Ethernet cable links a LAN port on my home router to port 1 on the switch. The four computers and Synology use ports 2–6, and the Comet X uses port 7. That leaves port 8 free. The router assigns IP addresses to devices set to obtain one automatically.

I also priced a whole-home UniFi upgrade with 10-gigabit Ethernet, three Wi-Fi access points, four cameras and a new NAS. The gigabit Netgear was enough to get the rack online with equipment I already owned.

Share a monitor, keyboard and mouse

The Comet X is a keyboard, video and mouse switch (KVM). Each computer connects to one numbered channel. HDMI carries the picture. A USB cable in the matching port carries keyboard and mouse input. The Comet X sends the selected computer’s picture to the monitor through its single HDMI output. I can also select and control a computer from the browser console. Comet X setup guide

The Netgear provides the Comet X with a network connection. An Anker USB-C adapter supplies power because the Netgear has no Power over Ethernet.

Route and label the cables

I planned three cable routes, viewed from behind the rack.

  • Run power down the left side. Keep the extension strip and adapters outside the rack.
  • Run Ethernet down the right side, towards the Netgear switch.
  • Run each HDMI and USB pair up the centre, towards the Comet X.

I’ll label both ends of each cable and bundle cables with reusable straps. A loose loop at each computer leaves enough slack to pull it forward and reach its ports.

What I want to run

I plan to start with K3s, a lightweight version of Kubernetes, on the EQR6. The Mac mini can run Ollama for local AI experiments, with a browser chat interface on the EQR6. The Pi 3 can run Pi-hole, and the Synology can hold shared files and backups.

Once I assemble the rack, I’ll open the Comet X console from my laptop, select each channel in turn and check that video, keyboard and mouse all work.
